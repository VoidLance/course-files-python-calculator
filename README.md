# Python Calculator

A small command-line calculator written in Python. It reads two numbers and performs addition, subtraction, multiplication, or division.

## Features

- Four basic arithmetic operations
- Accepts decimal numbers
- Operation names are case-insensitive
- Uses only Python's standard library

## Getting started

You need Python 3 installed. No additional packages are required.

From the project directory, run:

```bash
python3 calculator.py
```

On Windows, you may use `python calculator.py` instead.

Enter the two numbers, then choose an operation (`add`, `subtract`, `multiply`, or `divide`). For example:

```text
Input X: 12
Input Y: 4
Add, Subtract, Multiply, Divide: divide
3.0
```

Inputs must be valid numbers. Division by zero is not handled by the program.
